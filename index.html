Tips cetak PDF

  1. Pilih Save as PDF sebagai tujuan cetak.
  2. Matikan Headers and footers agar tidak ada teks browser di tepi kertas.
  3. Aktifkan Background graphics agar gradien dan warna tabel ikut tercetak.
  4. Gunakan skala 100% dan margin Default.

Pengaturan ini berada di dialog cetak browser dan hanya perlu diatur sekali.
